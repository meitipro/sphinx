Locks and seals are SHA-256 over UTF-8 text joined with a bar, `|`, as lower-case hex. The contract computes them with Python's `hashlib`, the site with the browser's SubtleCrypto, and both are tested against the same vectors (`tests/vectors.json`): `tests/test_static.py` checks the contract and runs `web/scripts/check-vectors.mjs` for the site.

```text
lock = sha256(answer + "|" + notes + "|" + salt)
seal = sha256(answer + "|" + salt + "|" + lower_case(address))
```

- **The address is in the seal**, in lower case with its `0x`, so a seal copied from another player can never be opened: the copier's address gives a different hash.
- **A bar is refused in the answer and the salt.** The notes, in the middle, may hold one. A lock then splits one way only, so a host cannot lock `piano` with notes `keyboard|…` and reveal `piano|keyboard` instead.
- **The salt** is 8 to 80 letters, digits or dashes. The site uses `crypto.randomUUID()`.
- **Exactly the bytes.** The contract hashes what it is sent, without trimming. The site trims an answer before sealing it and stores the trimmed text in the ticket, so the reveal sends the same bytes.

## The code

{/* include: web/lib/hash.mjs */}
```js title="web/lib/hash.mjs"
/**
 * Locks, seals and salts, byte for byte the contract's (contracts/sphinx.py
 * lock_of and seal_of). Plain JavaScript so the site, the Node scripts and the
 * vector check run this exact file.
 *
 *   lock = sha256(UTF-8 "answer|notes|salt")
 *   seal = sha256(UTF-8 "answer|salt|address"), the address in lower case
 *
 * tests/vectors.json holds the shared test vectors; scripts/check-vectors.mjs
 * checks this file against them and tests/test_static.py runs that check.
 */

/** Lower-case hex sha256 of a string's UTF-8 bytes, with SubtleCrypto (browser and Node alike). */
export async function sha256Hex(text) {
  const digest = await globalThis.crypto.subtle.digest('SHA-256', new TextEncoder().encode(text));
  return Array.from(new Uint8Array(digest), (b) => b.toString(16).padStart(2, '0')).join('');
}

export function lockOf(answer, notes, salt) {
  return sha256Hex(`${answer}|${notes}|${salt}`);
}

export function sealOf(answer, salt, address) {
  return sha256Hex(`${answer}|${salt}|${String(address).toLowerCase()}`);
}

/** A fresh salt: a random UUID, 36 letters, digits and dashes, inside the contract's 8 to 80. */
export function newSalt() {
  return globalThis.crypto.randomUUID();
}

/** Why a text cannot be an answer the contract will open, or an empty string. */
export function answerProblem(text, max = 80) {
  if (text.includes('|')) return 'An answer cannot contain a bar, |.';
  if (text.length > max) return `At most ${max} characters.`;
  return '';
}
```
